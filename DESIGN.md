# Auto Claude Design System & Impeccable Context (`DESIGN.md`)

## 1. Design Direction & Aesthetic Philosophy
- **Theme Personality**: **Oscura Midnight** (Dark) & **Warm Editorial Paper** (Light) — an intentional, high-craft engineering command center inspired by Linear, Raycast, and Fey.
- **Anti-Slop Commitment**: Every view in Auto Claude Web and every frontend/UI deliverable generated by Auto Claude agents must pass `npx impeccable detect` with **0 anti-patterns**.

## 2. Typography & Hierarchy
- **Primary Sans (`--font-sans`)**: `'IBM Plex Sans', 'Instrument Sans', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
  - **Banned Overused Fonts**: Never default to generic `Inter`, `Roboto`, `Space Grotesk`, `Plus Jakarta Sans`, or `Fraunces`.
- **Monospace (`--font-mono`)**: `'JetBrains Mono', 'Fira Code', 'SF Mono', monospace`
- **Font-Size Floor**:
  - Minimum functional UI text size is **`12px` (`text-xs` / `0.75rem`)**. Never use `text-[10px]` or `text-[11px]` for badges, labels, shortcuts, or metadata.
- **Semantic Heading Hierarchy**:
  - Maintain strict `h1` -> `h2` -> `h3` nesting without skipping levels (`[skipped-heading]`).
  - Ensure distinct typographic scale between `h1` (`>= 18px` / `text-lg`), `h2` (`>= 14px–16px`), and body copy (`14px`) to prevent `[flat-type-hierarchy]`.
  - Apply `text-balance` (`text-wrap: balance`) on multi-line headings and `text-pretty` (`text-wrap: pretty`) on empty-state descriptions.

## 3. Color & Contrast (WCAG AA >= 4.5:1)
- **Dark Mode (`.dark` — Oscura Midnight)**:
  - `--background: #0B0B0F`, `--card: #121216`, `--foreground: #E6E6E6`
  - `--primary: #D6D876` (`--primary-foreground: #0B0B0F`)
  - `--muted-foreground: #868F97` (contrast `>= 5.5:1` on dark surfaces)
- **Light Mode (`:root` — Warm Off-White)**:
  - `--background: #F2F2ED`, `--card: #FFFFFF`, `--foreground: #0B0B0F`
  - `--primary: #595B24` (`--primary-foreground: #FFFFFF`, contrast `6.7:1` on white)
  - `--accent: #EFEFE0`, `--accent-foreground: #454719` (contrast `8.2:1`)
  - `--muted-foreground: #4E5A65` (contrast `6.1:1` on `#F2F2ED`)
- **Semantic Status & Pill Badges**:
  - Always pair translucent backgrounds (`bg-*-500/15`) with high-contrast text in both modes:
    - Blue: `text-blue-700 dark:text-blue-300`
    - Emerald/Green: `text-emerald-800 dark:text-emerald-300` / `text-green-800 dark:text-green-300`
    - Amber/Yellow: `text-amber-800 dark:text-amber-300`
    - Orange: `text-orange-800 dark:text-orange-300`
    - Red/Destructive: `text-red-700 dark:text-red-300`
    - Purple: `text-purple-700 dark:text-purple-300`
  - Never use hardcoded `text-gray-600`, `text-gray-500`, or `bg-blue-50` without theme-aware tokens (`text-muted-foreground`, `bg-card`, `border-border`).

## 4. Layout, Cards & Motion
- **No Nested Cards (`[nested-cards]`)**: Never place bordered card containers (`.border.rounded-md`) inside an outer bordered card (`.border.rounded-lg.bg-card`). Use subtle surface fills (`bg-muted/40`) or horizontal section dividers (`border-t border-border pt-4`) instead.
- **No Icon-Tile Stacks (`[icon-tile-stack]`)**: Avoid stacking large decorative icon boxes above centered headings and paragraphs. Pair icons inline with headings.
- **Smooth Exponential Motion**: Use `cubic-bezier(0.22, 1, 0.36, 1)` or `cubic-bezier(0, 0, 0.2, 1)` instead of bounce/elastic keyframes.
